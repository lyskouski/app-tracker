座右铭：小步前行，进步可见，习惯长存。

关键词：番茄钟,提醒,计划,日历,专注,自律,自我关怀,待办,清单,进度,打卡,激励,目标,作息

**Zwyka** -- 一款开源、跨平台、无广告、无限制的习惯追踪应用。
本项目的目标是打造一款直观、高效且包容的习惯追踪应用，
让用户轻松管理自己的习惯，同时确保不让任何人掉队。

### 功能
- 习惯
  - 标题、备注、图标（2,000 多个 Material 图标）和颜色（调色板或自定义 RGB / HEX）
  - 每周的活跃日；非活跃日以 "—" 标记
  - 归档（停用）习惯：该习惯显示为灰色、排在最后，并在日程中隐藏
  - 数值目标，例如 10000 步：每天记录达成的数值，完成率 = 数值 / 目标
  - 要避免的习惯（创建时设定）：图标被划掉，无标记的日子为 100%，标记为 100% 减去其百分比，连续天数统计无标记的日子
- 习惯日历（主页）
  - 今天：以列表显示今天的习惯，已完成和已跳过的排在下方；向右滑动标记为完成（数值目标会询问数值），向左滑动跳过，点击打开当天状态，点击图标编辑习惯，长按打开习惯详情
  - 每周：每个习惯一张卡片，显示其活跃日和本周的标记；点击卡片打开今天的状态，点击图标编辑习惯，长按卡片打开习惯详情
  - 总览：按天（行）排列的习惯（列）：最近 66 天以及接下来的 5 天
  - 每个习惯的当日进度：`·` 已开始，`\` 25%，`|` 50%，`/` 75%，`X` 100%，`▣` 超过 100%
  - 点击日期，可将该日所有未标记的习惯标记为跳过（"—"）
  - 连续天数：连续标记的天数（"—" 的日子不会中断连续记录）
- 统计
  - 最近 66 天的每日完成率（%）
  - 习惯详情：描述、目标、过去一年每天的完成情况（类似 GitHub 贡献图）、最长和当前连续天数
  - 习惯的目标：(+) 按钮添加目标（标题、描述以及新建或已有的分组）；目标按名称分组，点击可标记为已完成，全部完成的分组排在最后，↑ 将分组上移；长按目标可编辑，长按分组可在确认后删除该分组及其所有目标
- 日程（日历）
  - 将习惯安排为 30 分钟、1 小时、2 小时或自定义时间段，在每周选定的日子重复，
    并可添加备注
  - 提醒（通知）
  - 添加到外部日历（Apple、Google、Microsoft）
- 计时器（从日程进入）
  - 显示已安排事件的未来 12 小时时钟、当前事件的倒计时以及接下来的事件
  - 保持屏幕常亮，事件开始时振动，结束时询问习惯的完成情况
  - 番茄钟：15 分钟、30 分钟、1 小时、2 小时或自定义，可选关联习惯
- 设置
  - 数据导入 / 导出
- 用户体验
  - 自动化：Siri 快捷指令（完成、累加或跳过习惯；今天剩余的习惯）以及供 Tasker、Automate 或 `adb` 使用的 Android Intent；当前显示的屏幕会立即更新
  - 无障碍（WCAG 2.1）：每个操作都有供读屏软件使用的名称，两种主题下对比度清晰易读，文字随系统字号缩放
