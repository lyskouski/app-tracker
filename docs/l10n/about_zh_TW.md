關鍵字：番茄鐘,提醒,計畫,行事曆,專注,自律,自我照顧,待辦,清單,進度,打卡,激勵,目標,作息

**Zwyka** -- 一款開源、跨平台、無廣告、無限制的習慣追蹤應用程式。
本專案的目標是打造一款直覺、高效且具包容性的習慣追蹤應用程式，
讓使用者輕鬆管理自己的習慣，同時確保不讓任何人落後。

### 功能
- 習慣
  - 標題、備註、圖示（2,000 多個 Material 圖示）和顏色（調色盤或自訂 RGB / HEX）
  - 每週的啟用日；未啟用的日子以 "—" 標示
  - 封存（停用）習慣：該習慣會顯示為灰色、排在最後，並在行程中隱藏
  - 數值目標，例如 10000 步：每天記錄達成的數值，完成率 = 數值 / 目標
  - 要避免的習慣（建立時設定）：圖示被劃掉，無標記的日子為 100%，標記為 100% 減去其百分比，連續天數統計無標記的日子
- 習慣行事曆（主頁）
  - 今天：以清單顯示今天的習慣，已完成和已略過的排在下方；向右滑動標記為完成（數值目標會詢問數值），向左滑動略過，點擊開啟當天狀態，點擊圖示編輯習慣，長按開啟習慣詳情
  - 每週：每個習慣一張卡片，顯示其活躍日和本週的標記；點擊卡片開啟今天的狀態，點擊圖示編輯習慣，長按卡片開啟習慣詳情
  - 總覽：依日期（列）排列的習慣（欄）：最近 66 天以及接下來的 5 天
  - 每個習慣的當日進度：`·` 已開始，`\` 25%，`|` 50%，`/` 75%，`X` 100%，`▣` 超過 100%
  - 點選日期，即可將當天所有未標記的習慣標記為略過（"—"）
  - 連續天數：連續標記的天數（"—" 的日子不會中斷連續紀錄）
- 統計
  - 最近 66 天的每日完成率（%）
  - 習慣詳情：描述、目標、過去一年每天的完成情況（類似 GitHub 貢獻圖）、最長與目前連續天數
  - 習慣的目標：(+) 按鈕新增目標（標題、描述以及新的或既有的群組）；目標依名稱分組，點擊可標記為已完成，全部完成的群組排在最後，↑ 將群組上移；長按目標可編輯，長按群組可在確認後刪除該群組及其所有目標
- 行程（行事曆）
  - 將習慣安排為 30 分鐘、1 小時、2 小時或自訂時段，於每週選定的日子重複，
    並可加上備註
  - 提醒（通知）
  - 加入外部行事曆（Apple、Google、Microsoft）
- 計時器（從行程進入）
  - 顯示已安排事件的未來 12 小時時鐘、目前事件的倒數計時以及接下來的事件
  - 保持螢幕常亮，事件開始時震動，結束時詢問習慣的完成情況
  - 番茄鐘：15 分鐘、30 分鐘、1 小時、2 小時或自訂，可選擇關聯習慣
- 設定
  - 資料匯入 / 匯出
- 使用者體驗
  - 自動化：Siri 捷徑（完成、累加或略過習慣；今天剩餘的習慣）以及供 Tasker、Automate 或 `adb` 使用的 Android Intent；目前顯示的畫面會立即更新
  - 無障礙（WCAG 2.1）：每個操作都有供螢幕閱讀器使用的名稱，兩種主題下對比清晰易讀，文字隨系統字型大小縮放
