## Kebijakan Privasi

Tanggal berlaku: 2026-10-24

Terima kasih telah menggunakan aplikasi kami ("Zwyka", "Aplikasi"). Kebijakan Privasi ini menjelaskan cara kami
menangani data Anda dan menjamin privasi Anda saat menggunakan Aplikasi. Kami berkomitmen untuk melindungi informasi
pribadi Anda dan memberikan transparansi mengenai data yang kami kumpulkan serta cara penggunaannya.

### Pengumpulan dan Penggunaan Data

Aplikasi tidak mengumpulkan data pengguna, informasi pribadi, atau data sensitif apa pun. Kami tidak mengharuskan Anda
untuk mendaftar atau memberikan data pribadi apa pun untuk menggunakan fitur-fitur Aplikasi. Aplikasi tidak memuat
layanan iklan, analitik, atau pelacakan apa pun.

### Penyimpanan dan Keamanan Data

Semua data yang dimasukkan ke dalam Aplikasi (kebiasaan, tandanya, jadwal, dan pengaturan) disimpan secara lokal di
perangkat Anda, atau di penyimpanan peramban web Anda untuk versi web. Kami tidak menyimpan data Anda di server kami.
Anda dapat mengekspor data Anda ke dalam sebuah file dan mengimpornya kembali; file tersebut hanya disimpan di tempat
yang Anda pilih.

### Notifikasi

Aplikasi dapat menampilkan pengingat untuk kebiasaan yang dijadwalkan. Pengingat dibuat dan dikirimkan secara lokal di
perangkat Anda oleh sistem operasinya, tanpa mengirimkan data Anda kepada kami. Di Android, Aplikasi meminta izin untuk
menampilkan notifikasi, menjadwalkan alarm yang tepat waktu, dan memulihkan pengingat setelah perangkat dimulai ulang.

### Layanan Pihak Ketiga

Aplikasi dapat menambahkan kebiasaan yang dijadwalkan ke kalender eksternal (Apple, Google, Microsoft) hanya jika Anda
memilih untuk melakukannya. Dalam hal ini, judul, waktu, dan catatan kebiasaan diteruskan ke layanan yang dipilih, dan
kebijakan privasi layanan tersebut berlaku. Versi web Aplikasi dihosting oleh penyedia pihak ketiga (GitHub Pages,
terCAD), yang dapat memproses informasi teknis (seperti alamat IP) untuk menyajikan Aplikasi. Kami menganjurkan Anda
untuk meninjau kebijakan privasi setiap layanan pihak ketiga yang mungkin Anda akses melalui Aplikasi.

### Pembaruan Kebijakan Privasi

Kami berhak memperbarui atau mengubah Kebijakan Privasi ini sewaktu-waktu tanpa pemberitahuan sebelumnya. Setiap
perubahan kebijakan akan dipublikasikan di dalam Aplikasi. Dengan terus menggunakan Aplikasi setelah adanya perubahan
pada Kebijakan Privasi, Anda setuju untuk terikat oleh ketentuan yang diperbarui.

### Hubungi Kami

Jika Anda memiliki pertanyaan, kekhawatiran, atau permintaan terkait Kebijakan Privasi ini atau praktik pengelolaan
data Aplikasi, silakan hubungi kami di https://github.com/lyskouski/app-tracker/issues

### Kesimpulan

Privasi Anda penting bagi kami, dan kami berkomitmen untuk menjaga kerahasiaan dan keamanan data Anda selama
menggunakan Aplikasi. Yakinlah bahwa kami tidak mengumpulkan atau menyimpan informasi pribadi apa pun. Dengan
menggunakan Aplikasi, Anda menyetujui ketentuan Kebijakan Privasi ini.

Terima kasih telah memercayakan privasi Anda kepada kami saat menggunakan Aplikasi kami.
