### Market Takeaways

- **Direct niche competitors**: OpenHabitTracker / ididit!, LifeTracker, Lunatask and Streak are the only apps on desktop + mobile (+ web); OpenHabitTracker is also free, open source and account-free — the closest match to Zwyka.
- **Privacy-first / no-account is table stakes** (≈40 apps claim it: Kado, Tend, Constanza, Habo, Yolmira, HabitForge, SevenGrid, LogZero…); Zwyka must win on UX and features, not on privacy alone.
- **Anti-streak trend**: weekly/monthly targets, scores or "fresh week" replace strict chains (SetHabits, mostly, SevenGrid, Kado EMA score, Dopaloop 0–5 intensity, Steadia, ididit!/OpenHabitTracker overdue %, Aspra, Live Level).
- **Graded progress is rare**: only rytmio (intensity levels), Allez! (0–100 partial credit), Dopaloop (0–5) and Super Simple Habit Tracker (color-coded performance ranges) approach Zwyka's graded marks.
- **Gamification (≈20 apps) and AI coaching (≈10 apps) are the most crowded segments** — low value for differentiation.
- **Common in strong newcomers**: interactive widgets, numeric/timer/counter habit types, skip/rest days, CSV/JSON export, Shortcuts/App Intents, Apple Health auto-complete.

## Zwyka: Current Strengths

| Feature Name | Description | Pros / Cons |
| --- | --- | --- |
| ⭐⭐⭐ True cross-platform | Android, iOS, Desktop (JVM), Web (PWA/Wasm) from one codebase | **+** Among popular apps only Habitify/TickTick match it, and they need an account; Loop is Android-only, Streaks Apple-only, HabitKit mobile-only. **−** Desktop/Web can't notify while closed; OpenHabitTracker (open source, same platforms + self-hosted sync) is a direct niche competitor |
| ⭐⭐⭐ Free, open source, no account | No subscription, no habit limit, local-only data | **+** Strong vs. Habitify (3 free habits), HabitKit/HabitNow paywalls. **−** No sync between devices (see gaps); many newcomers are also no-account |
| ⭐⭐⭐ Graded progress | `·` `\` `\|` `/` `X` `▣` (0–100%+) per day | **+** Rare: most apps are binary done/not-done or require a numeric target; only niche apps offer similar (rytmio, Allez!, Dopaloop, Super Simple Habit Tracker). **−** No absolute values (e.g. "6 of 8 glasses") |
| ⭐⭐ All-habits table view | Habits × days grid, 66 days back + 5 ahead, pinned headers | **+** Overview of all habits at once (similar to Loop/Way of Life/Kado matrix/Habit Pocket). **−** Hard to read on small phones with many habits |
| ⭐⭐ Time-blocking schedule | Day calendar with habit slots, repeats, notes, reminders, export to Apple/Google/Microsoft calendars | **+** Rare in dedicated trackers (TickTick, Lunatask, Joi Planner offer comparable). **−** Day view only, no week view |
| ⭐⭐ Localization | 26 locales, incl. RTL (fa, ar) | **+** Wider than nearly all competitors (Loggr 24, OpenHabitTracker 20). **−** Maintenance cost for every new string |
| ⭐ Streaks & today's progress | Day streak per chain, overall % of today in the corner | **+** Covers the core motivation loop. **−** No best/longest streak, no per-habit stats |
| ⭐ Metrics | Daily completion % graph (66 days) | **+** Simple. **−** Global only; no per-habit, weekly/monthly or yearly view |
| ⭐ Import / Export | Backup & restore of the database | **+** Data ownership. **−** Manual; no import from other apps; no open format (CSV/JSON) |

## Zwyka: Gaps (Proposed Features)

| Feature Name | Description | Pros / Cons |
| --- | --- | --- |
| ⭐⭐⭐ Home-screen widgets | Interactive widgets to mark today's habits without opening the app; lock-screen widgets and iOS Live Activity (Loop, HabitKit, Streaks, Open Habit, Habituator, Duse, Kado, Loggd; Habitify's are tap-to-open only) | **+** Top-cited reason users pick Loop/Streaks; cuts check-in friction. **−** Per-platform code (Glance on Android, WidgetKit on iOS); no Desktop/Web equivalent |
| ⭐⭐⭐ Flexible frequency | "N times per week/month", "every N days", biweekly/yearly, besides fixed weekdays (Loop, HabitNow, Habitify, Kado, Tend, Routine Tracker, Ritus, jeden.day) | **+** Fits real habits (gym 3×/week on any day); fixes streaks breaking on unplanned days. **−** Streak and "—" logic becomes more complex; DB migration |
| ⭐⭐⭐ Measurable goals | Numeric target + unit per habit (8 glasses, 30 min, 10 km), counter and timer types, multiple check-ins per day; graded mark is derived from the value (Loop, Habitify, Streaks, Kado, Duse, HabitFriend, Tend, digitally) | **+** Most requested beyond yes/no; maps naturally onto existing 25/50/75/100/100+ states. **−** Extra input step per check-in; needs a fast entry UI |
| ⭐⭐⭐ Device sync | Keep data in sync between phone, desktop and web (Habitify, TickTick, Habitica, LifeTracker, Lunatask) | **+** Multi-platform app without sync loses most of its value. **−** Server cost/privacy; mitigate by syncing via the user's own storage (Google Drive / iCloud / WebDAV file), a self-hosted server (OpenHabitTracker, Beaver, Habsum) or E2E encryption (Metamorphic, Lunatask, LifeTracker, init.Habits) |
| ⭐⭐⭐ Per-habit statistics | Heatmap (GitHub-style, HabitKit, Streak, Loggd), completion rate per week/month/year (rytmio), current vs. best streak, weekday breakdown (OpenHabitTracker), Loop-style "habit strength" / Kado EMA score | **+** Strongest retention driver in reviews; HabitKit's heatmap is its whole brand. **−** Screen space on mobile; must stay simple |
| ⭐⭐ Skip / rest / vacation | Mark a day as skipped, plan rest days, or pause a habit for a period without breaking the streak (Habitify, Way of Life, Streaks, Habituator, SevenGrid, Quiet Control, Habit Pocket, HabitForge, Wolia) | **+** Reduces "streak-loss" churn; reuses existing "—" concept. **−** Can be abused to inflate streaks |
| ⭐⭐ Streak-free progress model | Weekly/monthly targets or a consistency score instead of an all-or-nothing chain; a missed day doesn't reset progress (SetHabits, mostly, SevenGrid, Kado EMA, Dopaloop, Steadia, OpenHabitTracker "overdue %") | **+** Strongest trend among new apps in 2026; fits graded marks better than streaks. **−** Streaks are still a key motivator for many; offer both rather than replace |
| ⭐⭐ Goal direction & ranges | Per-habit goal type: at least / at most / exact / range, with color feedback (HabitFriend, SevenGrid "at most", Super Simple Habit Tracker ranges, jeden.day & Wolia limits) | **+** Natural extension of graded marks (e.g. 100% inside range, lower outside); covers limits without a separate "quit" mode. **−** More options in the habit editor |
| ⭐⭐ Negative (quit) habits | Track "avoid" habits: success = not done, "days since" counter, quit milestones with health benefits and money saved (Streaks, NowAgo, Yolmira, HabitIt, Sober not Sorry, Owl) | **+** Large use case (smoking, sugar, social media). **−** Inverts grading/streak semantics; UI must make it clear |
| ⭐⭐ Actionable reminders | "Done" / "Snooze" buttons in notifications, answerable without unlocking (Loop, Habitify, Momentum, Constanza) | **+** Extends existing reminders cheaply; one-tap check-in. **−** Platform-specific (Android actions, iOS categories); not on Web |
| ⭐⭐ Archive habits | Hide finished/paused habits but keep their history (Loop, HabitKit, Habo, Habituator) | **+** Keeps the table compact; history is not lost as with delete. **−** Needs an "archived" view |
| ⭐⭐ Open export formats | CSV/JSON export per habit and per day (Loop, Habituator, Habit Pocket, Kado, mostly, Loggr, OpenHabitTracker JSON/YAML/TSV/Markdown) | **+** Spreadsheet analysis; makes Zwyka a safe choice (no lock-in); prerequisite for import by others. **−** Schema must be versioned |
| ⭐⭐ Import from other apps | Import Loop CSV/DB, HabitKit, Habitify, HabitBull exports (Open Habit imports HabitKit, OpenHabitTracker imports Google Keep) | **+** Lowers switching cost — direct user acquisition from Loop (Android-only) users. **−** Formats change; one parser per app |
| ⭐⭐ Daily note / mood | Short note or photo per habit per day, or a day journal with mood (Habitify, Way of Life, Habo, Today Habit Tracker, Tangerine, Ritus "emoji of the day") | **+** Context for misses; reflection improves adherence. **−** Overlaps with schedule notes; extra data to export |
| ⭐⭐ Health & auto-tracking | Auto-complete from Apple Health / Health Connect (steps, workouts, sleep, mindful minutes), other apps (Oura, Duolingo) or phone signals (location, usage) (Streaks, Habitify, Grit, Habituator, Level Habits, Potential, Habyte) | **+** Zero-effort tracking; strong on iOS. **−** Mobile only; permissions & store review overhead |
| ⭐⭐ Groups / time of day | Categories or Morning / Afternoon / Evening sections, filter in the table (Habitify, HabitNow, Kindled, OpenHabitTracker) | **+** Scales the table to 15+ habits. **−** More settings; conflicts with current column ordering |
| ⭐⭐ Routines (habit stacks) | Ordered sequence of habits with durations started as one flow; backward scheduling from a target end time (Roz, awakee, HabitNow, init.Habits) | **+** Builds directly on Zwyka's time-blocking schedule; strong ADHD audience. **−** Needs a "run routine" UI with timers |
| ⭐⭐ Adaptive & progressive plans | Shift a missed occurrence to the next free day (Routine Tracker), suggest lowering frequency when struggling (Steadia), ramp-up or taper plans that recalibrate after slips (HabitIt, Level Habits) | **+** Differentiating and offline-friendly (rule-based, no AI needed). **−** Hard to explain; must stay predictable |
| ⭐ Milestones & celebrations | 7/30/66/100-day milestones, confetti on reaching a target (Kindled, Habit-Maker, digitally, NowAgo, HabitYear) | **+** Cheap motivation without full gamification. **−** Easy to overdo; must respect minimalism |
| ⭐ Two-way calendar sync | Show device calendar events in the schedule and keep habit slots in sync (Joi Planner, PomoPlan, Lunatask, SelfOS) | **+** Upgrade of existing one-way export; avoids double booking. **−** Calendar APIs differ per platform; Web limited |
| ⭐ Timer / Pomodoro | Start a timer from a habit; elapsed time fills the graded mark (TickTick, Streaks, Habitify, Grit, Kado, Streak, Loggd) | **+** Natural link with schedule slots and measurable goals. **−** Background execution limits on mobile/Web |
| ⭐ Watch app | Check-in from Apple Watch / Wear OS, complications (Streaks, Habitify, TickTick, Wolia, Habituator, HabitMinder) | **+** Fastest check-in path. **−** Separate targets; small audience vs. cost |
| ⭐ Gamification | Achievements, levels, rewards, commitment stakes (Habitica, Finch, HabitForge, Levla, HabitTrove, stickK) | **+** Motivation for some users. **−** Most crowded segment; distracts from minimalist positioning; significant design effort |
| ⭐ Social accountability | Share progress with a friend / group (HabitShare, Habitica parties, HabitFriend, Metamorphic family plan, Aspra partner) | **+** Proven adherence booster. **−** Requires backend & accounts — contradicts privacy-first model |
| ⭐ Share progress image | Export a habit card/heatmap as an image (HabitIt share cards, Xtreeks) | **+** Free marketing via social posts; no backend. **−** Minor value for users |
| ⭐ App lock & encrypted backup | PIN / biometric lock and password-encrypted backup files (HabitNow, Habo, Finale, Eudaemon, LogZero) | **+** Privacy for sensitive habits. **−** Platform-specific auth APIs; lost password = lost backup |
| ⭐ Templates & onboarding | Suggested habits and preset routines on first launch (Fabulous, Habitify, HabitMinder 50+, Respawn 100+, New Habit 300+, Allez! 64) | **+** Faster first value; better store conversion. **−** Content must be localized into 26 languages |
| ⭐ Shortcuts / automation | Siri Shortcuts / App Intents, Android intents, URL scheme, REST API (Streaks, Habitica, Open Habit, Kado, Habo, Beaver) | **+** Power users and integrations (Tasker, IFTTT). **−** Low demand overall |
| ⭐ Correlations | Chart habits, mood and numeric values together to reveal what influences what (Habit Pocket, LogZero, Loggr) | **+** Uses data Zwyka already has; no backend. **−** Needs enough history to be meaningful |
| ⭐ Default-done habits | "Mark only if missed" mode: days count as done unless the user marks a miss (OnTrack) | **+** Near-zero effort for stable habits. **−** Inflates stats if the user forgets to mark misses |
| ⭐ Desktop accessibility | Full keyboard navigation, screen-reader support, themes (OpenHabitTracker) | **+** Desktop/Web users expect keyboard-first UX; low cost in Compose. **−** Ongoing QA per platform |
| ⭐ AI insights | Coach suggestions and weekly summaries (Habitify AI, MicroHabit AI miss prediction, HabiTick, HabitIt); or an MCP server so the user's own assistant reads the data (Loggd, Leaf) | **+** Trending in 2026 marketing; MCP keeps data local. **−** Needs cloud LLM or on-device model; privacy concerns |

## Recommended Order

1. Widgets, flexible frequency, measurable goals — table stakes where Zwyka currently loses users to Loop / Streaks / Habitify.
2. Per-habit statistics (heatmap + best streak) and skip/vacation — retention.
3. Device sync via user-owned storage — unlocks the cross-platform advantage while staying account-free.
4. Open export (CSV/JSON) and import from Loop / HabitKit — acquisition from Android-only and paywalled competitors.
5. Goal ranges and a streak-free score option — cheap extensions of graded marks that match the strongest 2026 trend.
